# Agent corruption implementation and experiments

> For agentic workers: use subagent-driven-development; execute tests before implementations and review actual diffs. User authorized continuous design/implementation/experiments on GPUs 4–7. Preserve unrelated work, no commits required.

Goal: derive annotated chemically executable H from frozen original reference semantics, preserve N_raw, render a disclosed canonical N/H pair without changing the original instruction, and evaluate whether H lowers answer accuracy relative to no CoT. v9, v11 and v12 all failed the two-model development objective; their completed results are archived. v12 increased structural severity and completed answers, GT probes and entropy: only Chem-R had B<A. The separate v13 source-state diagnostic is in [its own plan](2026-09-20-source-state-diagnostic.md); its completed observation is recorded separately below.
Architecture: Python controller owns fixed plans and budgets; gpt-5.4-mini reviews reference alignment and selects from program-enumerated candidates, isolated contexts audit; a deterministic renderer realizes N/H and RDKit executes molecular edits; tokenizer-specific labels and paired evaluation are saved separately from model-visible text.
Tech stack: Python, RDKit, httpx/Poe, Transformers tokenizers, vLLM.

## Locked decisions for this implementation round

- Preserve process_evaluation_data formal_cot_trace as immutable N_raw, never reverse-restore N from H. N_visible is a canonical rendering of checked original semantic fields plus correct-plan-derived local connectivity, not the verbatim original CoT. Both N/H use the same template; no complete correct or H product SMILES is rendered. N is computed without H.
- Current v12 severe defaults: at least one structural root, six distinct wrong semantic nodes, and forty error tokens for EACH tokenizer (`--candidate-mode severe --min-roots 1 --min-nodes 6 --min-tokens 40`). Save actual thresholds per manifest. Historical v11 used 2/4/12; never change archived thresholds. Repeated mentions are not additional roots.
- Enlarge fragment / anchor / removal-set changes and combine 1–3 structural dimensions with forward-executed consequences. Do not add numeric +1 roots to reach the count. A removal set remains one semantic dimension even when it spans multiple branches. The older numeric-root logic is historical or explicit standard-mode behavior, not the v12 severe default.
- Examine a bounded proposal pool (at most 768 proposals / 36 returned graph-valid candidates), apply render/density/leakage checks, then let the Agent approve at most six eligible candidate IDs. Deterministically select minimum executed H-vs-GT-equivalent clean-product achiral Morgan Tanimoto, tie by candidate ID. Save policy max_graph_distance_among_agent_approved_feasible_candidates; this is finite-pool fingerprint distance, not maximum graph-edit distance over chemistry space. No victim outputs enter per-origin construction selection.
- Report separate product Tanimoto, original-source heavy-atom edit footprint, typed structural/numeric roots, and optional text/token ratios. These describe an intentionally severe screened intervention distribution; they do not estimate natural error frequency, a natural Poisson distribution, or victim error probability. No weighted severity score.
- Immutable input instruction and indexed SMILES are compared directly with the source record at release and preparation.
- Origin split, random seed 20260920: 18 development origins stratified 6 per task; remaining 132 heldout. Development may iterate; heldout evaluated once per frozen released version and any subsequent adaptation must label it reused validation, never fresh test.
- Initial pilot 3 origins then development18; expand only after quality gates. Persist every rejected plan, all API calls, and entire frozen configuration. No SHA fields/dependencies.
- Main causal test puts N/H inside the assistant's native think prefix with identical question/system in A/B/C/E. Existing supplied-reasoning placement remains an explicit separate control. Never change instruction or corrupt input caption.
- v11/v12 program quality gates: executable reference equals benchmark GT; approved H execution; stereo policy; immutable roots; complete changed-node annotations/bindings; density; no complete correct/H product or complete answer component; no oracle/corruption cues. Model reference/conformance reviews are single-call diagnostics, not release gates; retain every disagreement and report counts. Program acceptance is not unanimous chemical certification. Transport/schema failures still remain failures.
- Primary empirical objective, separate from per-origin construction acceptance: development B accuracy < A on both models; also report B vs C, exact and primary accuracy, similarity, baseline-correct flip rate, Wilson 95% intervals, exact McNemar. Failure triggers a documented design revision, not deletion of difficult origins. The inequality is an empirical objective, never guaranteed.
- Teacher-forced GT log-probability scores one fixed GT token event, not all chemically correct outputs. Conditional entropy with n=8/T=.8/p=.95 completed for both v12 models after answers and GT probes, retaining invalid/missing samples. Secondary sampled accuracy averages correct/8 within each origin, then equally across 14 origins; it is not best-of-eight and does not replace the greedy gate. Gradient/attention/training are not implemented. FTS uses achiral Morgan similarity; primary matching ignores minor components. No input-corruption positive control because the original instruction must stay unchanged.
- Current v11/v12 review contract: four isolated single-call contexts with Poe gpt-5.4-mini, limit ten actual HTTP calls including failures. No repeat voting until agreement or free-text semantic repair. SELECT still chooses from program-eligible candidates; reference/conformance opinions remain stored as agreed/disputed. All per-origin selection excludes victim outputs, but v10/v11 strategy changes were informed by v9 development results and v12 severity changes by v11 development results. This is iterative development, not unseen-test evidence.
- Local environments use surviving edit centers, radius1–3, recursive ring/non-SINGLE-bond closure, SINGLE-only H caps and rejection of ambiguous stereo caps. Require >=6 SMILES characters, <=16 heavy atoms and <=half physical product, excluding whole correct/H products and their components. This is an explicitly capped graph projection, not a stable reagent/intermediate. N/H local radius/coverage need not match.
- root_ids encode computational ancestry, not a proven nonzero marginal causal effect. Changed complete SMILES slots are relative-to-canonical-clean semantic node labels, not independent per-atom truth labels. Token labels project separately for each tokenizer and the full real prompt.
