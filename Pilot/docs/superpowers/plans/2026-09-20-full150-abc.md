# Full 150-origin task-interpretation ABC experiment

The user explicitly requested full-corpus testing after the four-origin v17
diagnostic. This authorizes evaluation of the former 132 heldout origins; this
run is exploratory full-corpus evaluation, not a previously untouched heldout
claim. Preserve v17 and publish the generalized protocol separately as
`agent_full_task_interpretation_v1` in `agent_corruption_v18/full150`.

v17 has a fixed four-case acylation inventory, so exact v17 text recipes cannot
be applied to 50 add, 50 delete and 50 substitute cases. The generalized design
keeps its principle: a mistaken interpretation of required operations, followed
by executable, conditionally consistent structural and quantitative claims.
No old H is copied into the new corpus. C retains the original visible N except
explicit complete-answer removal. H is a deterministic typed re-expression of
the reference with false operation values. This introduces a declared prose/style
contrast relative to C and is not byte-style-equivalent to v17.

All 150 original instructions, indexed sources and GTs remain exact. Recover a
full-component/stereo-exact clean reference first. Four special references need
explicit graph/cap/stereo handling: a replacement categorized as deletion, a
dual-site transformation, and two aromatic N attachments. Stereo assignment is
fixed in the clean reference from its GT and never inferred from target outcomes.
During H execution it remains an explicit fixed policy, not a new oracle call.

Construct a bounded source-derived wrong-plan pool (at most 768 proposals),
recompute source valence adjustments, execute, exclude correct products and full
answer leakage, and verify all rendered facts. Retain a bounded severity-ranked
pool before asking gpt-5.4-mini to select a chemically interpretable mistaken
operation. No target model outcome enters generation. Require six distinct
wrong semantic nodes and forty annotated standalone H tokens for each model;
repeated mentions and alias nodes do not increase the distinct-node count.
Product molecular formula is a separately computed downstream claim.

Keep clean-only review, candidate selection and conditional fidelity audit as
separate Poe requests, with bounded retries and cached full request contents.
Program chemistry/labels are gates; reviewer disagreements are retained rather
than described as unanimous approval. A malformed candidate selection or API
failure remains a recorded failure, not silent substitution with old H.

Freeze code, prompts, originals, candidate pools and both tokenizer snapshots.
Prepare and review are resumable phases; failures stay in the 150-origin summary.
Publish N/H pairs only for accepted records. Do not launch a subset under the
full150 name: the runner requires 150 accepted origins and 300 pair rows.

v12 sampling/context/prefix settings. Sequence ChemDFM-R-14B then Chem-R-8B.
Report per-model A/B/C Accuracy and Morgan similarity with fixed n=150, paired
B-A/B-C and all missing/invalid/truncated outcomes. Dedicated nohup log begins
with PID and process-group stop instruction. No automatic outcome-based revision
