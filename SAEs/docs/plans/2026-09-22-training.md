# ChemDFM-R Layer 26 SAE implementation

User-authorized scope: relocate SAE corpus and audit out of Pilot_v2, prepare runnable multi-architecture training, evaluation and W&B tracking. Do not start GPU extraction or scientific training in this work session. CPU synthetic validation is allowed.

## Scientific contract
- ChemDFM-R-14B; 1-based Layer 26 is model.layers[25] output, post-token residual before final norm; d_in=5120.
- External chemistry chat text, teacher forcing with complete existing context. Extract eligible assistant tokens only, preserving frozen character/token masks and no prefix shift. No independent sequence concatenation, truncation, padding activations or reference metadata inputs.
- Use frozen molecular-group train/validation selections under data/v1/selections/pilot_10m. Never split activation rows to make validation. Pilot evaluation data remains held out.
- First budget: 10,000,474 train +443,731 validation tokens. Float16 raw cache needs approximately 99.6 GiB for both; metadata extra. Cache is reusable across architectures.
- Defaults BatchTopK, 16,384 features, k64, batch1024; provide TopK, JumpReLU, Matryoshka and sparsemax attention alternatives. This is a starter experiment, not a selected best SAE.
- Fit normalization on train activations only and store it in checkpoints. Evaluate reconstructions after inverse normalization; distinguish reconstruction quality, feature usage and causal LM fidelity from hallucination detection quality.

## Work and ownership
1. Parent: migration receipt, active paths, standalone environment, activation input/mask and extractor with atomic chunked caches, documentation and integration checks.
2. sae_models: library-backed models, model APIs and numerical CPU tests.
3. sae_training: bounded cache reader/shuffling, training, checkpoint/resume, W&B and configs, CPU smoke tests.
4. sae_evaluation: token-weighted reconstruction/feature metrics and optional clean/reconstructed/ablated LM loss evaluation, tests.

## Shared APIs
- sae_models.build_sae(model_cfg,device); training_step(sae,x,step,dead_mask) returns loss, sae_out, feature_acts, losses; reconstruct(sae,x) returns recon,z.
- metrics.ReconstructionMetrics.update(x,recon,z), .compute() -> numerical dict.
- activation_inputs.encode_document(row,LocalTokenizer) -> input_ids, assistant_positions; iter_selected_documents(corpus_root,selection_path) yields full corpus rows, preserving selection order.
- Cache manifest version1: complete status; layer26; block_index25; activation_site post_block_residual; d_in5120; dtypefloat16; splits train/validation, each n_tokens and shards with path,n_rows,sha256. Each shard is a .npy matrix. Companion JSONL document segments map shard row spans to document and token positions; preserve source and group IDs.
- Checkpoints must include model/config, fitted normalization, optimizer, schedule/step, cache fingerprint, sampling/RNG state; exact resume test is required.
